## 下载与启动

从下载页取得 Windows 完整 ZIP 和配套 `.zip.sha256`。完整解压到新文件夹后运行“群友启动器.exe”，再点击“开始游戏”，无需安装 Unity。

不要下载 GitHub 自动生成的 Source code ZIP，它只是这个下载仓库的文件，不是游戏。

## 更新

公开包已预置更新地址；使用启动器“检查更新”，确认后下载、校验并安装。也支持手动导入完整 ZIP、回退上一版；不覆盖本地军表和设置。游戏运行时禁止安装更新，请先退出所有游戏窗口。

旧版启动器若尚未配置地址，可点“更新地址”填入：

`https://raw.githubusercontent.com/mohsunil/zhulu-galaxy-downloads/main/update/windows.json`

网络无法连接 GitHub 时，可使用可信来源的完整 ZIP 和哈希手动导入。联机双方请使用相同版本。
